# QA Bug Reporting Project — SauceDemo

## Descripción

Proyecto de pruebas manuales enfocado en validación funcional, exploratory testing y documentación de bugs estilo Jira utilizando SauceDemo.

El proyecto incluye:
- Login testing
- Functional testing
- Exploratory testing
- Bug reporting
- Checklist QA
- Evidencia visual
- Test execution summary

# Escenarios probados

## Login válido
Validación de autenticación correcta usando credenciales válidas.

## Login inválido
Pruebas con credenciales incorrectas y validación de mensajes de error.

## Usuario bloqueado
Validación de restricciones de acceso.
